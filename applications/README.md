# Application Manifests

Application workloads managed via Argo CD.

## Applications

- **api-gateway**: Core API gateway deployed from the `freecloudinitiative/api-gateway` repository.
- **compute-service**: Compute management service deployed from the `freecloudinitiative/compute-service` repository.
- **database-service**: Database management service deployed from the `freecloudinitiative/database-service` repository.
- **iam-service**: Identity and Access Management service deployed from the `freecloudinitiative/iam-service` repository.
- **storage-service**: Storage management service deployed from the `freecloudinitiative/storage-service` repository.
- **terminal-gateway**: Terminal gateway service deployed from the `freecloudinitiative/terminal-gateway` repository.
